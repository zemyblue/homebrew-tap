# Zemyblue Deckhand

## How do I install these formulae?

`brew install zemyblue/deckhand/<formula>`

Or `brew tap zemyblue/deckhand` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zemyblue/deckhand"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
